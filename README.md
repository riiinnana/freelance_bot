# freelance_bot

Telegram-бот для первичной фильтрации фриланс-вакансий для дизайнера.

Бот принимает текст вакансии, определяет подходящие направления дизайна,
извлекает бюджет и отмечает неподходящие предложения по стоп-словам.

## Возможности

- Анализ текста вакансии, отправленного в Telegram.
- Поиск направлений дизайна по ключевым словам.
- Извлечение указанного бюджета.
- Отсев вакансий по стоп-словам.
- Персональный профиль: каждый пользователь выбирает свои направления,
  минимальную сумму за проект и строгость отбора.
- Результат с одним из статусов:
  - 🟢 подходит;
  - 🟡 требует ручной проверки;
  - 🔴 не подходит.

## Профиль пользователя

Настройки больше не зашиты в код — они свои у каждого пользователя бота и
редактируются в меню «⚙️ Настройки»:

- **Направления.** Справочник `directions.py` разделён на три блока —
  2D-графика, 3D и анимация с видео. Экран настроек двухуровневый: сначала
  блок, внутри блока галочки. Порядок выбора задаёт приоритет: направление,
  отмеченное первым, поднимает вакансию выше в выдаче.
- **Минимальная сумма за проект.** У каждого своя.
- **Ссылка на портфолио.** Спрашивается при первом запуске, подставляется
  в отклик заказчику.
- **Строгий режим.** Включён по умолчанию: показываются только выбранные
  направления. Если выключить, смежный дизайн тоже попадёт в выдачу — со
  статусом 🟡 и в конце списка.

Блок 3D разделён на сферы, которые реально встречаются на фриланс-рынке:
предметная визуализация, архитектура и интерьеры, персонажи, техника
(hard surface), игровая графика и модели под 3D-печать.

## Как ищутся ключевые слова

Поиск идёт по шаблонам, привязанным к началу слова, а не по кускам текста.
Звёздочка на конце ключевого слова означает «и любое окончание»:
`"презентаци*"` найдёт презентацию, презентации и презентаций. Слово без
звёздочки должно совпасть целиком, поэтому `"3d"` не находится внутри
`3days`, а `"wb"` — внутри `webflow`.

Стоп-слова делятся надвое. Универсальные (`filter_settings.py`) отклоняют
работу, которая вообще не относится к дизайну: копирайтинг, вёрстка, SEO,
таргет. А направления, которые подходят не каждому — 3D, анимация,
видеомонтаж — это обычные пункты справочника: кто-то их включит, кто-то нет.

Сейчас вакансии можно вводить вручную, а также искать в MVP-режиме в открытых
веб-лентах подключённых Telegram-каналов. Их список редактируется в
`source_settings.py`. История публикаций и устранение повторов будут добавлены
на следующем этапе.

## Структура проекта

```text
config.py        # Общие настройки приложения
directions.py    # Справочник направлений, разделённый на блоки
filter_settings.py # Универсальные стоп-слова и сумма по умолчанию
filter.py        # Разбор вакансии и примерка её под профиль
profiles.py      # SQLite-хранилище профилей пользователей
main.py          # Telegram-бот и обработчики сообщений
source_settings.py # Редактируемый список источников и лимиты выдачи
application_settings.py # Шаблон отклика и фразы под каждое направление
applications.py    # Поиск Telegram-контакта и создание ссылки с черновиком
rejections.py      # SQLite-хранилище отклонённых вакансий
collectors/       # Сборщики вакансий из внешних источников
test_filter.py   # Автоматическая проверка фильтра и работы профилей
test_profiles.py # Автоматическая проверка хранилища профилей
test_collector.py # Автоматическая проверка разбора Telegram-ленты
test_applications.py # Автоматическая проверка откликов и Telegram-ссылок
test_rejections.py # Автоматическая проверка хранилища отклонений
test_proxy.py    # Проверка подключения к Telegram API через proxy
```

Проверка вакансии разделена на два шага. `classify_vacancy` читает текст и
не зависит от пользователя, поэтому её результат одинаков для всех и его
достаточно посчитать один раз. `evaluate_for_user` берёт готовый разбор и
быстро сверяет его с профилем, уже не перечитывая текст.

## Требования

- Python 3.10 или новее.
- Токен Telegram-бота.
- Библиотеки `aiogram`, `aiohttp` и `python-dotenv`.
- Локальный HTTP-proxy `http://127.0.0.1:12334`, если используется текущая
  конфигурация в `main.py`.

## Установка

```powershell
git clone https://github.com/riiinnana/freelance_bot.git
cd freelance_bot
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install aiogram aiohttp python-dotenv
```

Если PowerShell запрещает активацию окружения, выполните один раз в текущем
профиле:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

## Настройка

Создайте в корне проекта файл `.env` и добавьте в него токен бота:

```env
BOT_TOKEN=ваш_токен_бота
```

Не добавляйте `.env` в Git: он уже указан в `.gitignore`.

В текущей версии `main.py` отправляет запросы через proxy
`http://127.0.0.1:12334`. Перед запуском бота убедитесь, что proxy запущен и
доступен, либо измените эту настройку в коде под свою среду.

## Запуск

```powershell
python main.py
```

После запуска откройте чат с ботом в Telegram и отправьте `/start`.
При первом запуске бот предложит отметить направления — без этого поиск не
работает. Позже их можно изменить в «⚙️ Настройки».
Кнопка «🔎 Найти вакансии» показывает одну наиболее подходящую вакансию.
По кнопке «✉️ Написать заказчику» Telegram откроет чат с предзаполненным
черновиком отклика; сообщение отправляете только вы. Кнопка «✖️ Отклонить»
скрывает вакансию для вашего пользователя и показывает следующую.

## Проверка

Запустить автоматические тесты:

```powershell
python -m unittest -v
```

Проверить доступ к Telegram API через настроенный proxy:

```powershell
python test_proxy.py
```

## Планы дальнейшей разработки

Планируется добавить хранение вакансий в SQLite, устранение дубликатов,
параллельный опрос каналов и фоновый сбор вакансий, а также персональные
уведомления о новых подходящих вакансиях.

Отдельно нужно доработать разбор бюджета: «от 5000 ₽» читается как точная
сумма, а сокращения «5к» и «5 тыс.» не распознаются. Список ключевых слов
стоит пополнить по реальным публикациям, когда накопится их история.
