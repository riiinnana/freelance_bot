# freelance_bot

Telegram-бот для первичной фильтрации фриланс-вакансий для дизайнера.

Бот принимает текст вакансии, определяет подходящие направления дизайна,
извлекает бюджет и отмечает неподходящие предложения по стоп-словам.

## Возможности

- Анализ текста вакансии, отправленного в Telegram.
- Поиск направлений дизайна по ключевым словам.
- Извлечение указанного бюджета.
- Отсев вакансий по стоп-словам.
- Персональный профиль: каждый пользователь выбирает свои направления,
  минимальную сумму за проект и строгость отбора.
- Результат с одним из статусов:
  - 🟢 подходит;
  - 🟡 требует ручной проверки;
  - 🔴 не подходит.

## Профиль пользователя

Настройки больше не зашиты в код — они свои у каждого пользователя бота и
редактируются в меню «⚙️ Настройки»:

- **Направления.** Справочник `directions.py` разделён на три блока —
  2D-графика, 3D и анимация с видео. Экран настроек двухуровневый: сначала
  блок, внутри блока галочки. Порядок выбора задаёт приоритет: направление,
  отмеченное первым, поднимает вакансию выше в выдаче.
- **Сумма за проект.** Минимум свой у каждого. Можно задать и потолок —
  вакансии дороже показываться не будут; по умолчанию его нет.
- **Формат работы.** Любой, только разовые задачи или только постоянное
  сотрудничество.
- **Ссылка на портфолио.** Спрашивается при первом запуске, подставляется
  в отклик заказчику.
- **Строгий режим.** Включён по умолчанию: показываются только выбранные
  направления. Если выключить, смежный дизайн тоже попадёт в выдачу — со
  статусом 🟡 и в конце списка.

Всего 24 направления. Блок 3D разделён на сферы, которые реально встречаются
на фриланс-рынке: предметная визуализация, архитектура и интерьеры, персонажи,
техника (hard surface), игровая графика и модели под 3D-печать. В блоке
анимации отдельно вынесены 3D-анимация, анимация персонажей и риггинг.

## Формат работы

Бот отличает разовую задачу от постоянного сотрудничества по словам в тексте:
«на постоянной основе», «оклад», «часов в неделю» — с одной стороны,
«разовая задача», «к завтра», названное количество работ («20 слайдов») —
с другой. Прямое указание на постоянную работу перевешивает: «нужно 10
карточек в неделю на постоянной основе» — это долгосрок, хотя объём назван.

Определившийся формат показывается меткой на карточке вакансии. Списки слов
редактируются в `commitment.py`.

Важное ограничение: большинство объявлений про длительность прямо не пишут.
Такие вакансии остаются без метки и **показываются при любой настройке
формата** — если прятать их, выдача схлопнется. Фильтр убирает только явно
противоположные.

## Как ищутся ключевые слова

Поиск идёт по шаблонам, привязанным к началу слова, а не по кускам текста.
Звёздочка на конце ключевого слова означает «и любое окончание»:
`"презентаци*"` найдёт презентацию, презентации и презентаций. Слово без
звёздочки должно совпасть целиком, поэтому `"3d"` не находится внутри
`3days`, а `"wb"` — внутри `webflow`.

Стоп-слова делятся надвое. Универсальные (`filter_settings.py`) отклоняют
работу, которая вообще не относится к дизайну: копирайтинг, вёрстка, SEO,
таргет. А направления, которые подходят не каждому — 3D, анимация,
видеомонтаж — это обычные пункты справочника: кто-то их включит, кто-то нет.

## Сбор вакансий

Бот сам обходит открытые веб-ленты подключённых Telegram-каналов и складывает
публикации в базу. Сбор фоновый и общий для всех пользователей: каналы
опрашиваются раз в `COLLECTION_INTERVAL_MINUTES` минут независимо от того,
сколько человек пользуется ботом. Нажатие «🔎 Найти вакансии» в сеть не ходит
вообще — оно читает базу и отвечает сразу.

Список каналов и интервал редактируются в `source_settings.py`. Недоступный
канал не прерывает сбор из остальных и попадает в лог, а не в чат.

## Структура проекта

```text
config.py        # Общие настройки приложения
directions.py    # Справочник направлений, разделённый на блоки
commitment.py    # Разовая задача или долгосрок: слова и определение
keywords.py      # Общий разбор списков ключевых слов
filter_settings.py # Универсальные стоп-слова и сумма по умолчанию
filter.py        # Разбор вакансии и примерка её под профиль
profiles.py      # SQLite-хранилище профилей пользователей
main.py          # Telegram-бот и обработчики сообщений
source_settings.py # Редактируемый список источников и лимиты выдачи
application_settings.py # Шаблон отклика и фразы под каждое направление
applications.py    # Поиск Telegram-контакта и создание ссылки с черновиком
vacancies.py     # SQLite-хранилище вакансий и устранение повторов
vacancy_actions.py # SQLite-хранилище действий по вакансиям
storage.py       # Путь к базе и настройки подключения
error_reports.py # Отправка ошибок бота владельцу в Telegram
collectors/       # Сборщики вакансий из внешних источников
collection.py    # Фоновый сбор: цикл и один заход
test_filter.py   # Автоматическая проверка фильтра и работы профилей
test_profiles.py # Автоматическая проверка хранилища профилей
test_collector.py # Автоматическая проверка разбора Telegram-ленты
test_collection.py # Автоматическая проверка фонового сбора
test_applications.py # Автоматическая проверка откликов и Telegram-ссылок
test_commitment.py # Автоматическая проверка формата работы и потолка
test_storage.py  # Автоматическая проверка подключения к базе
test_error_reports.py # Автоматическая проверка отправки ошибок
test_vacancies.py # Автоматическая проверка хранилища и повторов
test_vacancy_actions.py # Автоматическая проверка действий по вакансиям
test_proxy.py    # Проверка подключения к Telegram API через proxy
```

Проверка вакансии разделена на два шага. `classify_vacancy` читает текст и
не зависит от пользователя, поэтому её результат одинаков для всех: он
считается один раз при сборе и хранится в базе рядом с публикацией.
`evaluate_for_user` берёт готовый разбор и сверяет его с профилем, уже не
перечитывая текст.

## Устранение повторов

Одно объявление часто перепечатывают в нескольких каналах, и `source_id` у
копий разные — сравнивать приходится тексты. Точного совпадения мало: каждый
канал дописывает свою подпись, иногда длиннее самой вакансии. Поэтому повтор
ищется по доле содержательных слов вакансии, найденных в уже известной
публикации: служебная лексика объявлений и промо-подписи каналов из сравнения
исключаются, а метрика считается от более короткого текста — так длинный футер
не мешает узнать перепечатку.

Совсем короткие объявления по словам не сравниваются: у них слишком мало
содержательных слов, и случайное совпадение слишком вероятно. Для них
работает только точное совпадение текста.

## Требования

- Python 3.10 или новее.
- Токен Telegram-бота.
- Библиотеки `aiogram`, `aiohttp` и `python-dotenv`.
- HTTP-proxy, если из вашей сети Telegram недоступен напрямую.

## Установка

```powershell
git clone https://github.com/riiinnana/freelance_bot.git
cd freelance_bot
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install aiogram aiohttp python-dotenv
```

Если PowerShell запрещает активацию окружения, выполните один раз в текущем
профиле:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

## Настройка

Создайте в корне проекта файл `.env` и добавьте в него токен бота:

```env
BOT_TOKEN=ваш_токен_бота
PROXY_URL=http://127.0.0.1:12334
ADMIN_CHAT_ID=ваш_telegram_id
```

Не добавляйте `.env` в Git: он уже указан в `.gitignore`.

`PROXY_URL` необязателен: если строку не указать или оставить пустой, бот
работает напрямую. Задавайте его, только когда Telegram из вашей сети иначе
недоступен — тогда перед запуском убедитесь, что proxy поднят.

`ADMIN_CHAT_ID` тоже необязателен. Если он задан, ошибки бота присылаются
этим сообщением в Telegram, а не остаются только в консоли: и падения при
обработке сообщений, и падения фонового сбора. Повторы одной и той же ошибки
подавляются на час, иначе сбой в фоновом цикле присылал бы сообщение каждые
15 минут. Если бот потерял связь с Telegram, отчёт по той же причине не
дойдёт — консольные логи остаются последней линией.

## Запуск

```powershell
python main.py
```

После запуска откройте чат с ботом в Telegram и отправьте `/start`.
Команда `/help` показывает, что бот умеет.
При первом запуске бот предложит отметить направления — без этого поиск не
работает. Позже их можно изменить в «⚙️ Настройки».
Кнопка «🔎 Найти вакансии» показывает одну наиболее подходящую вакансию.
Под ней три действия:

- **✉️ Написать заказчику** — бот отмечает отклик, присылает ссылку на чат
  с готовым черновиком и сразу начинает искать следующую вакансию. Пока вы
  пишете заказчику, она успевает загрузиться. Сообщение отправляете только
  вы, бот ничего не рассылает.
- **⏭️ Пропустить** — вакансия уходит в конец очереди и вернётся, когда
  свежие закончатся.
- **✖️ Не подходит** — вакансия больше не показывается.

Кнопка отклика сделана не ссылкой, а обычной кнопкой намеренно: о нажатии
на кнопку-ссылку Telegram боту не сообщает, поэтому он не смог бы ни
отметить отклик, ни подготовить следующую вакансию заранее.

## Проверка

Запустить автоматические тесты:

```powershell
python -m unittest -v
```

Проверить доступ к Telegram API через настроенный proxy:

```powershell
python test_proxy.py
```
